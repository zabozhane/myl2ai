# Прогресс l2aiserver

Журнал этапов, решений и следующего шага. Обновляется после каждого значимого шага.

**Текущий этап:** 2 → «живое население» ботов (спецификация на согласовании).

**Следующий шаг:** согласовать спецификацию населения (100 ботов при старте, распорядок дня со сном, зоны кача по уровню).

| # | Этап | Критерий готовности | Статус |
|---|---|---|---|
| 1 | docker-compose: MariaDB + сборка и запуск чистого aCis | Захожу клиентом через winemac и создаю персонажа | ✅ готово |

## Сделано

- **Этап 1** — PR #1 (aCis 382 + MariaDB в Docker), PR #2 (папка `client/` вне git); оба смержены в `main`.
  Зашёл клиентом, создал персонажа, сражался с мобами. Сервер пока работает без геодаты.
- **Этап 2** — ветка `claude/project-thread-59obrh`. Проверено в игре: боты бьют мобов, растут в уровне, подбирают дроп.
  - Геодата: 139 регионов `.l2d`, сконвертированы штатным конвертером из `.l2j` (ChaosPaladin/l2j-geodata-project, эпоха Gracia/H5).
  - L2Autobots собирается в образе: патч перебазирован на чистую 382 с недостающими правками ядра, Kotlin 1.9 (`acis/autobots/README.md`).
  - Доработки ботов: ближайшая цель в радиусе 1000, уровни −5…+3, только в прямой видимости; подбор дропа до ответной атаки.
  - Адена автолутом для всех (`AutoLootAdena`), остальной дроп на землю.

## Решения

- aCis ревизия **382**, **JDK 11** — под неё написан L2Autobots, порт на свежую ревизию не делаем.
- Основа ботов — **L2Autobots** (Kotlin).
- Клиент Interlude C6 (протокол 746), пропатчен на `127.0.0.1`.
- Проект на Mac: `~/Projects/l2aiserver`, клиент в `client/` (в git не попадает).
- Docker на Mac — **Docker Desktop**.
- БД — MariaDB, схемы `l2_login` и `l2_game`.
- Геодата aCis 382 — только формат `.l2d`; текущий набор не родной Interlude (возможны невидимые стены на местах крепостей).
- Лут: адена автолутом всем, вещи падают на землю, боты подбирают сами.
- GM для тестов: аккаунт `test`, персонаж Afrodita (accesslevel 8), панель ботов `//a b`.

## Известные грабли

- Патч L2Autobots из репозитория автора неполный (сделан не от чистой 382): без правок ядра из `acis/autobots/` не собирается и боты не думают.
- Kotlin 1.7+: `minBy` бросает исключение на пустом списке, в коде L2Autobots заменён на `minByOrNull`.
- Ссылки на готовую `.l2d` геодату (MediaFire, MEGA, lineage2.org.uk) мертвы; живые раздачи — за регистрацией на форумах.

- Прежние вылеты и зависания клиента были вызваны **не** `L2CompiledShader.bin` — эту версию не перепроверять.
