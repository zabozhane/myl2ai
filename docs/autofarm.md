# Автобой для игрока (в стиле Essence) — спецификация

Статус: черновик, ждёт согласования владельца. Код не начат.

## Задача
Живой игрок нажимает кнопку, и его персонаж сам бьёт мобов вокруг: выбирает цель, использует скиллы,
пьёт банки, подбирает дроп. Нажал ещё раз — остановился. Как Auto Hunt в Lineage 2 Essence.

## Что уже есть
В L2Autobots (коммит `f990c61d`) есть заготовка `autofarm/`: `AutofarmManager` гоняет для обычного `Player`
тот же `CombatBehavior`, что и у ботов (тик 500 мс), настройки хранятся в таблице `character_autofarm`
(JSON по классу), окно Start/Stop через `TutorialShowHtml`, bypass `autofarm start|stop` уже проброшен
в `RequestBypassToServer`. Поддержаны все классы из `supportedCombatPrefs` (от 1-й профессии до 3-й).
Чего нет: способа открыть окно без GM-панели, окна настроек (кнопка Configure — `Not implemented yet`),
и поведение заточено под бота.

## Как включать
У клиента Interlude нет своей кнопки автобоя, поэтому:
- команда в чате `.autofarm` (перехват в уже существующем хуке `onChat`, сообщение в чат не уходит)
  открывает окно; `.autofarm on|off` — включить/выключить сразу;
- одна кнопка на панели: игрок делает макрос со строкой `.autofarm on` (или `off`) и кладёт его на шорткат;
- окно (Tutorial HTML, «вопросик» слева): Старт/Стоп, Настройки, текущий статус.

## Поведение (поверх `CombatBehavior`)
- Цель: ближайший моб в радиусе от точки старта (Essence-подобно: персонаж не уходит дальше радиуса от места,
  где нажал Старт), уровень −5…+3, только в прямой видимости, рейды и чемпионы — по настройке (по умолчанию нет).
  Мобы, которые бьют игрока, — в приоритете.
- Скиллы: атакующие и селф-бафы класса из `skillPreferences`, игрок может отключить отдельные.
- Банки и соски: только из инвентаря игрока (ничего из воздуха), пороги HP/MP/CP.
- Отдых: сесть при MP/HP ниже порога, встать при восстановлении (`Rester`), включается настройкой.
- Подбор дропа в радиусе 400 (`LootPicker`), можно выключить.
- Отличия от бота:
  - смерть → автобой выключается, персонаж лежит, игрок сам выбирает «В город» (бот же сам воскресает и бежит назад);
  - в городе, в мирной зоне, на олимпиаде, в осаде, при торговле/лавке автобой не стартует и выключается;
  - PvP: никогда не атакует игроков, даже если его бьют; при атаке игроком — сообщение;
  - ручное действие игрока (клик по земле/цели, скилл) ставит автобой на паузу на несколько секунд, а не борется с игроком;
  - выход из игры или дисконнект выключает автобой (оффлайн-кача нет).

## Настройки (окно «Настройки», хранятся в `character_autofarm`)
| Настройка | По умолчанию |
|---|---|
| Радиус поиска цели | 1000 (варианты 600 / 1000 / 1500) |
| Пороги банок HP / MP / CP | 50% / 30% / 70% |
| Сидеть для восстановления | вкл, сесть < 30% HP или < 20% MP |
| Подбирать дроп | вкл |
| Атаковать рейды/чемпионов | выкл |
| Список скиллов | все атакующие класса вкл |

Глобально в `data/autobots/config.xml`: `autofarmEnabled`, минимальный уровень (по умолчанию 1),
максимальная длительность сессии (по умолчанию без ограничений).

## Порядок работ
1. Включение: `.autofarm`, окно Старт/Стоп, выключение при смерти, в городе, при выходе.
2. Поведение игрока: радиус от точки старта, без PvP, без воскрешения, пауза при ручном управлении.
3. Окно настроек и сохранение.
4. Проверка в игре: персонаж воина и мага, банки, подбор, смерть.
