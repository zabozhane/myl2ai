## Ограничения

Логи обычных ботов пока не содержат периодических координат/статуса для всех путешествий.
Поэтому неизвестно, сколько персонажей молча стоят; нельзя объявлять весь онлайн проверенным.
Нет данных для уверенного различения мелких кругов и полезных обходов. Наблюдения простоя — повод
для диагностики, не автоматическое доказательство причины. Скрипт отделяет рестарты, отдых,
смерть, городские действия и владение офлайн-пати/квеста от непрерывного простоя.

## Подтверждённые места в коде для следующей задачи

- `LifeBehavior.currentSpot`: после исключения неудачных спотов последний fallback вызывает выбор
  с **пустым** набором исключений. Когда альтернатив нет, сразу выбирается та же проваленная цель.
- `WalkToSequence`: разбивает прямую к цели на участки, но не строит путь вокруг препятствия.
  `safeSegment` отвергает опасный прямой участок; полезный обход не ищется.
- Офлайн-персонаж сначала выбирает спот по прямой, а полный маршрут строит только в fallback.
  Возвращение после города тоже начинается без предварительного полного маршрута.
- Офлайн-детектор застревания считает неудачные проверки только при `!isMoving`: движение без
  приближения способно удерживать поездку. Лимита времени всего маршрута нет.
